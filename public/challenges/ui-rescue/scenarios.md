# Fem fasta scenarier

1. Köp en vara som privatperson och betala med kort.
2. Köp som företag med organisationsnummer och faktura.
3. Försök fortsätta utan e-post och hitta samt rätta felet.
4. Slutför hela flödet med endast tangentbord vid 320 px bredd.
5. Byt leverans från standard till express och förstå prisskillnaden före betalning.

Mät för varje scenario: slutfört/ej slutfört, antal interaktioner, kritiska tillgänglighetsfel och ett kort observationsfynd.
